# KOL 「新言论」必须按**出处日期**筛，不能按快照日期（2026-09-29）

## 陷阱
每日全量抓取会给名册里每个人都写一条当天快照（kol_independent.json / kol_store opinion.date=今天）。
但多数人当天没有新发言，子 agent 会把几周前的旧文章再总结一遍 → 直接列出 = 把旧话当新话。
实测 9/21–9/29：kol_store 去重后 457 条观点里，出处日期 ≥ 9/21 的只有 92 条 / 68 人；
9/28 当天有新发言的仅 10 / 153 人。

## 机械判定（不调 LLM）→ `tools/kol_highlights.py`
1. 取 opinion.date >= since，同人同 comments 去重；
2. 「新」= sources_json 里最新的**完整日期(YYYY-MM-DD)** >= since；只有月份(2026-09)/年份的算日期不明，不收；
3. 出处日期晚于今天（写错）丢弃并在 stderr 报数；
4. detail_status=none 或方向含「未找到」不收；thin 保留但标「公开信息有限」，不扩写；
5. 同人窗口内最多 N 条（默认 2），取出处最新的。
用法：`.venv/bin/python tools/kol_highlights.py [--since YYYY-MM-DD] [--per-kol 2] [--format md|json]`，默认 since=上一个交易日。

## 接入日报
日报 cron prompt 在 ⑪ 前加了 ⑪-A「KOL 当日精彩言论」：先跑脚本；窗口内**全部**条目都写（Chao 要「所有精彩言论」，不许只挑几条）；
段首抄脚本首行 N 人/M 条；同题材冲突只陈述谁说了什么；0 条写「今日无新公开言论」，禁止旧观点凑数。

## 周度/临时汇总的写法（Chao 认可的形态）
- 先报口径：窗口内有新发言 X 人/Y 条，其余 Z 人无新公开言论不计；按每人最新一条统计多/中/空。
- 按主题（不是按人）分组：共识 → 分歧（列双方+具体点位）→ 各板块；每条 人名（日期）观点+点位。
- 末尾点出「多流派不约而同指向的同一条线」（如 10Y 5.3–5.5%）和可检验的分歧时间点。
- 注明 thin 条数、以及全量抓取上线前的日期可能漏抓。
- 注意：显示层 redactor 会把部分人名替换成 ANONYMIZED_PERSON_x，数据本身没坏，别去改库。
