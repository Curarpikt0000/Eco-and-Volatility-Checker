# 加新板块:克隆渲染函数 + 侧栏菜单分组的坑(2026-10-14)

## 同类板块用「程序化克隆」而不是手写
铀短线图 = 金银短线图换标的。做法:写一次性补丁脚本,从 `dashboard.py` 取 `def _gs_tech_html` 源码,
`replace('gst-','urt-')`、`.gst`→`.urt`、函数名与文案,再替换「口径」句(注意原句里嵌了「某日 RSI 与截图核对一致」之类专属话术,必须换掉),插回文件。
元素 id 与 JS 局部变量带前缀,同页两份才不冲突。采集端同理:`fetch_xxx_tech` 复制 SMA/RSI 逻辑,新标的列表单独常量,单标的失败用旧缓存标「缓存」。
接线四处缺一不可:`generate()` 形参、`generate(...)` 传参(`gen_kwargs`,有「形参全部传入」门禁)、build_dashboard 抓取+传参、模板 `{xxx_html}`。
改前备份,补丁脚本先写文件再单独运行(长命令一条发会被审批超时拦)。

## 菜单分组是按标题关键词匹配 + 「同组被隔开则分段」
- 侧栏 GROUPS 在 f-string 模板里,JS 花括号要双写 `{{ }}`;往 GROUPS 里加组时别在「上一组那行中间」插入(第一次插错位置把对象劈开)。先定位该行行尾 `}},` 再在其后另起一行。
- 新板块放哪决定菜单:放在两个已有板块中间,它会被拆进相邻组/把整组切成两段(用户要「连续段」就是违反)。放到该主题段的**末尾**。
- 新建小组且仅 1 项会显示成「铀 1」,若夹在同一组两侧还会被「孤立离群」规则并回去;验收看 `.sn-group-hdr` 文本与计数,不要只看 DOM。
- 板块标题关键词必须真命中 GROUPS.match,否则落「其他」或并入相邻段。
- 验证:菜单 href 序列与 `.part-title`(含 .part-num) id 序列全等。
