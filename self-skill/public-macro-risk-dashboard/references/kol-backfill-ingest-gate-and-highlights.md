# KOL 一年期回填 + 入库门禁 + 日报「新言论」筛选（2026-09-29/30 实战）

## 1. 回填编排（100+ 人规模）
- 每批 2 人一个 `hermes -z` 子进程，每轮并发 5 批；编排脚本 `scratch/kol_bf_<batch>/orchestrate.sh`：
  flock 单实例、已有 `out/<id>.json` 跳过（断点续跑）、同人 2 轮无产出写 `[]` 放弃并列出、**每轮结束立即入库**。
- 实测：10 人约 20 分钟；106 人 11 轮约 4 小时；老名册缺月补齐只给子 agent `missing_months`，不重找已有月。
- 覆盖度指标：过去 12 个月「有言论的月数」。回填前 ≥9 月 63/163 → 回填后 133/163。
- 前台 terminal 禁 `&`；复杂 inline 命令会被 hardline 拦（parser limit）→ 写成 .sh 再 `bash x.sh` 后台跑。

## 2. 入库门禁 `tools/kol_bf_ingest.py`（机械判定，不调 LLM）
- G1 字段 / G2 窗口(≤今天) / G3 方向归一(看涨/看跌/中性) / G5 去重 / **G4 出处实测**：
  404/410/DNS 失败→拒；200 且页面无本人姓名→拒；403/429/超时→保留但计「无法自动核验」。
- kol_name 必须用名册 `display_name`（看板按它 join），kol_id 沿用 store 里该人已有 id。
- **先用造假对照组测门禁**：6 条假记录(404/无本人页/DNS/窗口外/非法方向/日期不全)+1 条真 → 必须 6 拒 1 过。每次改门禁都重跑。
- 门禁误杀的三个坑（修后回收 36 条）：
  - 名字含「/」（`Doomberg / Kuppy`、`Prechter / Elliott Wave International`）要按段各取姓；机构尾词(international/capital/research…)不能当姓。
  - x.com / linkedin 无登录返回 16 万字节 JS 空壳 → 只做存在性判断，记 unverifiable。
  - 去重音两边都折叠：Sløk↔Slok、Stöferle↔Stoeferle（ø→o, ö→oe…），页面正文也 fold 后再比。
- 子 agent 的自报存疑点要抽查：X 帖日期可由 status ID 反推 `((id>>22)+1288834974657)/1000`；机构署名文章（如 Santiago Capital）是否算本人要问 Chao。

## 3. 日报「KOL 当日精彩言论」`tools/kol_highlights.py`
- 全量抓取每天给每人写一条，但多数是旧文重述 → 只收 **sources 最新出处日期 ≥ 窗口起点** 的观点；只有月份的日期、晚于今天的日期、未找到 一律不收。
- Chao 2026-09-30 要求「更多细节，他们具体当天说了什么」：每条两层——标题行(人名/日期/方向/一句话/点位/链接) + 「原话要点」照录 detail（只删不增）。`--brief` 可退回一句话。周报用 `--since <周一> --per-kol 3`。
- 典型量级：日窗口 5 人/5 条；5 天窗口 30 人/37 条≈4 万字（Chao 说不在乎长度）。

## 4. 「转向」数字不可信的根因
- 每日抓取对同一篇旧文章会贴不同多空标签 → 9/30 标 29 人转向，出处晚于上期的只有 4 人。
- 汇报转向时必须核对依据出处日期；只有依据是新言论才算转向（待 Chao 拍板改判定规则）。
