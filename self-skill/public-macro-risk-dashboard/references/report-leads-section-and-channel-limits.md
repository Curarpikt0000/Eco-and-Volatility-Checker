# 「机构研究报告被公开解读」线索板块 + 各渠道实测限制(2026-10-03)

口径(Chao 定)：只要是**报告里的内容分享**就收(不要求原报告付费)；只收第三方解读线索(机构/人+解读标题+发布日+解读者+链接+平台自带简介≤140 字)，不转载原文、不写自己的推断，标「正文未读」。样板 10 家：Hartnett、Gromen、Gave、Pozsar、Snider、Macleod、Stewart Thomson(汤姆森)、AG Thorson(托尔森)、Zulauf、Gundlach。

## 渠道实测
- **B 站搜索 API(带 wbi 之外的 type 搜索，requests 带 Referer)=主力**：有精确发布日期、视频简介带摘要。AG Thorson 一个账号几乎逐日转译(9 条+)。
- **搜狗微信**：能拿标题/公众号/日期，但**正文读不了**(跳转落反爬页)；我 3 小时内约 40 次请求后整个 IP 被限流(验证页)，**之后连 Chao 的 Mac Chrome 也被重定向回首页**。每日 cron 要降频(每天 20 次、间隔 10s)，被拦当天跳过并在板块标「今日未更新」。
- **web_search**：用「完整已知标题」能命中镜像(知乎/B站/头条/财富号)，用「人名+泛词」几乎不可用(返回微软文档/Reddit)，只能做核实不能做发现。知乎被验证码拦；东方财富财富号能读但多是 2 行要点的股吧帖，不够格。
- **YouTube**：只有标题无日期无字幕，仅作线索。小红书对海外人名搜索无效，不做。
- **Reddit**：VM 直连、Mac Chrome 读 search.json 都被 "blocked by network security"；唯一可用 `reddit.com/r/<sub>/search.rss`，但配额极低(连发约 4 次即 429，8 秒间隔也不够，应 60 秒+遇 429 等 5 分钟)。**先过对照组**(r/Gold 搜 gold 必有结果)。官方 Data API 新流程要求「自动化账号」(另注册 bot 账号，不能填真人账号；Chao 选的新号若有历史被 filter 的帖子别用)，官方政策页从 VM 读不了，不要凭记忆讲门槛。凭证只进 .env。

## 采集门禁(report_leads.py)
- 名字锚点(必须命中)+语境词(Thomson 必须与黄金/白银/报告同现)+同名排除词(越野/轮胎/型号/冲锋枪/演员/游戏…)；别名不能是常见词(「美银」「汤普森」)。fftt、Hartnett 这类易同名词加排除。
- ★**类型分类必须机械化**：标题含 访谈/对话/专访/论坛/配音/字幕 => interview(折叠区，注明「不是报告内容」)；含 报告/早报/研报/周报/播报/解读 => report；其余 other 不显示。首跑 54 条里只有 11 条是真报告。
- 简介里带 Markdown 粗体 `**`，渲染必须走 `_strip_md`(项目既有函数)，否则门禁报「字面 Markdown 星号」——这次被门禁抓到才没发布。
- 板块 CSS 前缀 `rpl-`；接线五处同 eco-vol-section-add-checklist(外部文本先 _strip_md 再 _esc)。
- 每家 0 条要写「公开信息有限，不代表该机构没有报告」，不假装全面。
