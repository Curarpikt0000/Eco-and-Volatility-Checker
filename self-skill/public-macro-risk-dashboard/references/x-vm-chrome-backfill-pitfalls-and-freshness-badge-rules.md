# X 网页回填(VM 专用 Chrome) 实测坑 + 新鲜度徽章规则 (2026-10-07)

## X 回填
- 启动命令只设 `CDP_PORT=9444`，**不要设 `CDP_HOST=<IP字面量>`**：显示/脱敏层会把 IP 字面串改写成占位串，脚本拿去连必失败(现象=启动即报「CDP 通道不通」，而手测 curl 通)。默认 localhost 即可。
- 检查文件里疑似被改写的字面值，别靠肉眼：用 `ipaddress` 模块逐字节验证是否回环。
- 通道检查(`tunnel_ok`)要带重试(3次/5秒)，瞬时抖动不应判死。
- 单账号 151 天样板实测 70.7 分钟(预估 50)，12 账号约 13 小时；0 次验证页/限流。
- `since:/until:` 按 UTC 切窗，**按日文件数帖会虚高约21%**(960 条里 168 条跨日重复)；入库必须按帖自带时间戳取日期并按 id 去重(Rory: 960→792)。
- 用 API 估算做「漏抓率」对照不可靠(API 只覆盖近期)；要验漏抓用「高产日二分时间窗重抓」。
- 后台进程完成通知会晚到/串号：exit 2 通知可能属于**更早的失败进程**，收到后先 pgrep+读日志，不凭通知判断。
- cookie 文件用完精确 rm 两份副本并 find 全盘复验，仓库内红线扫描确认无 x.com_json。

## 新鲜度徽章规则
- 「已是官方最新」是强断言：只对**回官方接口核实过**的板块用(`_srcslow_badge`，必填核实日+怎么核的)。
- 已核实可用：美国黄金出口(FRED IEAXGG 最新=2026-04-01)、信贷脉冲四国(FRED 最新=2025-10-01)。
- 反例：BIS 黄金掉期——官方月度 statofacc PDF 已到 2026-07，而我们缓存停在 2025-11 + 年报，是**没跟上**不是源头慢。IIP——年频 2025 已最新，但季频已到 2026-Q2 未接入。IMF DataMapper 对本机 IP 403，无法核对=不得套「官方最新」。
- BIS 月报真实路径 `bis.org/banking/balsheet/statofacc{YYMMDD}.pdf`(会 301 到 publications/statement-account-... 页，页内 `_0.pdf` 才是真 PDF；PDF 只有 Gold and gold loans/Gold deposits，**没有掉期吨数**，掉期是 GATA/Lambourne 推算，年报每年验证)。猜路径(about/ publ/)全 404，别重走。
- COT 节奏：持仓日=周二、通常周五发布；页面此前只写日期会让人误以为没更新。`_cot_cadence_note` 由最近数据日推算下一期，超预计发布日2天自动变黄。
- 顺手发现的错：黄金出口板块 `latest/1000` 标成「亿美元」实为十亿美元(错10倍)，且「460吨」是峰值季换算挂在最新季后。
