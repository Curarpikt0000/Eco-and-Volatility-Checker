## 1. 港股通(南向)持股存量: 002 与 004 是同一份数据, 不可相加
- 接口: 东财 `RPT_MUTUAL_STOCK_HOLDRANKS`, `(MUTUAL_TYPE="002")(HOLD_DATE='YYYY-MM-DD')`, 日频, **只存约两年(2024-10-14 起)**, 全表 ~54 万行(002+004 各 ~27 万)。
- ★**重复计算陷阱**: 002(沪港通下) 与 004(深港通下) 返回**同一份**港股通全量持股(667 只, 持股数逐只完全一致)。两通道市值相加会翻倍(我先后报过 9.73、11.76 万亿港元, 真值≈5.88)。只取 002 一个通道; 落盘记 n_stocks 供核对。
- 北向侧该表无 001/003/005 行(None); 北向个股持股只有 `RPT_MUTUAL_HOLDSTOCKNORTH_STA` 的最新季末快照(2026-06-30、2026-09-30 两期), 按旧日期过滤为空。
- `RPT_MUTUAL_MARKET_STA`(MARKET_CODE=005) 只返回最近 4 期季末(2025-12-31 起), **每次运行并入本地存档**才积累历史。2026-09-30 新点 2.574 万亿(2.268%), 比 06-30 的 3.089 万亿(2.513%)低 5145 亿——含价格涨跌, 不等于外资净卖出。
- 单日抓取 ≈2.4 秒; 回填 ~470 个交易日 ≈19 分钟 → 采集器用「最近日期优先 + budget_s 限时 + 原子落盘(tmp+os.replace)」, 日更每次补缺 120 秒。采集器只在结束时落盘, 回填期间进度文件不变≠卡住。
- 交易日历复用南向日度净买入存档(cn_capital.json 的 south_d 键)。
- 实现: 项目 `src/fetchers/cn_capital_hk_hold.py`; 渲染接在「A 股资金面」③南向块末尾(持股存量线 + 同期恒指对比文字, 明写「存量含价格涨跌, 不等于净买入」)。

## 2. 探测/改文件的工具坑
- 终端工具会把命令里的 `&`(哪怕在 Python 字符串里, 如 print('a & b'))当「后台化」拦下 → 探测逻辑一律 write_file 成 /tmp/probe_xxx.py 再 python3 跑, 字符串里避免裸 `&`。
- 一次性大 heredoc 改受保护文件(dashboard.py)易审批超时被拦; 载荷 write_file 到 /tmp + 小补丁脚本(assert count==1)分开, 被拦后先 grep -c 查实物是否部分生效。
- 探测要先拿「必然存在的对照」: 用 2026-10-13 单日合计与 667/667 重叠只数才暴露翻倍, 否则会把 9.73 万亿写进页面。
