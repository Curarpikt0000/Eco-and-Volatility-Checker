# KOL「当日精彩言论」与周度汇总：按出处日期判新（2026-09-29）

## 用户需求
Chao 要日报加一段「KOL 当天的所有精彩言论」，并临时要「上周到今天所有 KOL 的言论和判断」汇总。

## 核心坑：全量抓取 ≠ 新言论
全量 prefetch 每天给 153 人各写一条，但多数人当天没新发言，子 agent 会把几周前旧文章再总结一遍。
直接读 kol_independent.json / 当日快照列出来 = 把旧话当新话。9/29 实测：153 人里窗口内真有新发言的仅 10 人；
9/21–9/29 共 457 条去重观点里只有 90 条（66 人）出处日期在窗口内。

## 判新规则（tools/kol_highlights.py，纯机械、不调 LLM）
1. kol_store 取 date>=since，同人同句 comments 去重；
2. 新 = sources 里最新**完整日期** >= since；只有月份（2026-09）= 日期不明，不收；
3. 出处日期晚于今天 = 写错，丢弃并报数；
4. detail_status=none 或方向含「未找到」不收；同人保留最新 N 条（默认 2）。
用法：`.venv/bin/python tools/kol_highlights.py [--since YYYY-MM-DD] [--per-kol 2] [--format md|json]`，默认 since=上一交易日。
日报 cron 步骤 ⑪-A 已接入：窗口内全部条目都写、段首写「新发言 N 人/M 条（名册 X 人）」、0 条写「今日无新公开言论」绝不凑数。

## 周度汇总写法（Chao 接受的形态）
- 先报口径：窗口内新发言 N 人/M 条，其余无新发言不计；方向分布按每人最新一条。
- 按主题（不是按 KOL 所在板块）组织：共识最强的放第一；每个主题列多空两边，人名+日期+一句话+点位。
- 显式点出「多人独立指向的同一关键位」（本次：10Y 5.3–5.5%）和「可检验的分歧」（金价 10 月见底 vs 破 $4,000，Curry 给了时间点）。
- 标出已被行情证伪的点位（如 Streible $4,350 已破）。
- 末尾说明 thin 条数不可当完整观点、以及抓取覆盖缺口（prefetch 上线前几天可能漏抓）。
