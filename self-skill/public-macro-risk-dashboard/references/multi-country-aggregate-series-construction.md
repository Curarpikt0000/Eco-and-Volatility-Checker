# 多国聚合时序（全球 M2 类）—— 口径声明与三道防错

2026-09-21 实现「全球货币供应 30 年 + 加速度」的实战笔记。

## 0. 先说口径，这类图没有官方版本

「全球货币供应」**无官方单一口径**，IMF/BIS/世界银行都不发布该数。
任何人画这张图都是自己聚合。页面必须写明：
「自行聚合五大经济体、按当期汇率折美元的**构造值**，非任何机构官方发布」。

## 1. 五国数据源（全部实测可用）

| 经济体 | 序列 | 源 | 起点 |
|---|---|---|---|
| 美国 M2 | `M2SL` | FRED | 1959-01 |
| 欧元区 M3 | SDMX | `data-api.ecb.europa.eu` | 1996-01（367 点） |
| 日本 M2 | `MD02'MAM1YAM2M2MO` | BOJ HTML 表 **MD02 第 9 列** | 存量列 2003-04 |
| 英国 M4 | `LPMAUYM` | BoE 官方 CSV | 1996-01 |
| 中国 M2 | — | 东财 | 2008 |

已排除：FRED OECD `MABMM301*`（2023-11 停更、中国 2018 断）、
世界银行「世界总计」（全 None）、世界银行欧元区（全 None）、国家统计局（403）。

实测 2026-07 合计 **108.76 万亿美元**，与公开的「全球 M2 约 110 万亿」吻合 → 聚合口径没错。

## 2. ★三道防错（每一条都会静默画错图）

**① 尾部残月造成假暴跌**
最新月常常只有部分经济体发布（实测 2026-08 只有中日 = 61 万亿），直接画上去是断崖式暴跌。
→ **只剔除尾部未满员月份**（不动中间的真实缺口），页面标注
「末尾 N 个月因部分经济体尚未发布而暂不显示」。

**② 同比只在覆盖国集合相同时才算**
否则 2008-01 中国加入那一刻，国家数变化会伪装成货币单月暴增 35 万亿。

**③ 解析外部 HTML 表必做数量级检查**
BOJ 页面里 1980 年起的那些列是**同比增速百分比**（值如 2、1.2），
M2 存量应是 1.2e7 亿円量级。代码里硬写 `fv > 1e6` 的护栏 —— 即便 BOJ 改版列位移，
小值会被直接拒绝而不是悄悄画错。

## 3. 历史缺口是数据边界，要画进图里而不是外推

```
1996-01 ~ 1998-12   2 国   美、英        ← 欧元 1999 才诞生，此前无 EUR 汇率
1999-01 ~ 2003-03   3 国   +欧元区
2003-04 ~ 2007-12   4 国   +日本         ← BOJ 存量列起点
2008-01 ~ 2026-07   5 国   +中国
```

把覆盖度表直接印在图下方。**不假装 30 年都完整** ——
任何声称「1996 年全球 M2」的图，那一段要么用马克法郎折算要么是估的。

## 4. 加速度（二阶导）才是这类图的价值

```
2021-02  +16.15   疫情放水顶峰   同比 +20.49%
2022-05  -16.33   急刹车         同比  +0.79%
```
32 点的反转 = 紧缩转折点。只看同比只能看到「从 +20% 降到 +0.8%」，看不出转折有多剧烈。
