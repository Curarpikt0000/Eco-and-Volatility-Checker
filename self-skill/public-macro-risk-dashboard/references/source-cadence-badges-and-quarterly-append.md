# 板块「更新频率」标注 / 低频源徽章 / 季频追加（2026-10-07 实战）

触发：Chao 问「怎么还是上周的数据」「每个图是不是真在更新」。结论先查源头节奏，不要先怪抓取。

## 1. 先判三类，再动手
- **源头本来低频且我们已是最新**（FRED 季度序列、BIS 年度、IMF 年度）→ 展示层写「⏳ 源头X更新·最新YYYY-MM-DD 已是官方最新」，**不得用 🟡「数据滞后」吓人**。
- **源头有更新、我们没跟**（BIS 月度掉期缺 8 个月、IIP 季频已到 2026-Q2）→ 补抓，不能套「已是官方最新」。
- **没法核对**（IMF DataMapper 对本机 IP 403）→ 保持原状，不下结论。
- 铁律：套「已是官方最新」徽章前必须**回官方接口实测**，写入 `verified_on` + 怎么核的（`_srcslow_badge(as_of,cadence,verified_on,src_note,extra)`，灰蓝 `.sb-slow`，与 `.sb-gray`=日期未知区分）。只对核实过的板块用。

## 2. COT 节奏（别再被「上周」误导）
- 持仓日=周二，CFTC 通常周五发布（联邦假日顺延）。10-07(周三) 最新就是 09-29 周；下一期 10-06 周要 10-09 才出。
- 核对法：Socrata `max(report_date_as_yyyy_mm_dd)` 对**全表 + 黄金 + 白银 + 对照组(原油/另一数据集 72hh-3qpy)** 都查；项目用的数据集 id 在 `src/config.py COT_SOURCE`(6dca-aqww)，别猜。
- 展示：`_cot_cadence_note(as_of)`——下一期 = 持仓日+7，发布 = +10；超预计发布日 2 天自动出 🟡。日期由数据算，不写死。

## 3. 季频追加到年频图（IMF IIP）
- `api.imf.org/external/sdmx/2.1/data/IIP/{ISO}.{A_P|L_P}.IIP.USD.{A|Q}?startPeriod=`，同一数据集，美国 2025-Q4 季频值 == 2025 年频值（口径相同，先验证再接）。
- 只追加**晚于最新年末**的季度点(`net_q`)，年频序列/`latest_*` 一律不动；季频取不到 → 页面自动退回年频。
- 柱状图：四国都有季频才用季频，否则整图退回年频（不混用期别）。
- 验证三件套：①年频序列与旧缓存逐点一致 ②去掉季频后 svg 与旧渲染逐字节相同 ③只缺一国季频时整体退回。测试写临时 cache 文件，`cmp` 确认真实缓存没被碰。

## 4. BIS 自营黄金掉期（GATA/Lambourne 月度推算）
- BIS 月报 PDF 路径已变：2026-08 起为 `bis.org/publications/statement-account-31-august-2026.pdf`；旧 `banking/balsheet/statofacc{YYMMDD}.pdf` 会 302 到 publication 页（HEAD 200 也可能是 HTML，需看魔数 `%PDF`）。
- PDF 里**没有**直接的 swaps 吨数，只有 Gold and gold loans / Gold deposits 两行，吨数是 Lambourne 推算。**不要自己推算。**
- 只写**读到原文正文**的值（月表、「from X to Y tonnes」原句）；只在搜索摘要里见到或靠 A−B 反推的月份（本次 2026-05、07）一律不写，缓存里留 `gaps_note`，页面显示「缺口」。
- 同日年报与月度并存时取年报（03-31=184，GATA 月度 181）。
- `fetch_bis_gold_swaps` 的「最新年报」必须取**最后一个 kind=annual 点**，补月度点后取 `pts[-1]` 会把月度误标成年报确认。

## 5. 单位自查（顺手抓到的真错）
黄金出口板块 `latest/1000` 标「亿美元」实为十亿美元，错 10 倍；百万美元→亿美元 = ÷100。吨数「≈460吨」是峰值季换算，被挂在最新季后面。**凡有单位换算的文案，渲染后用手算复核一遍。**

## 6. 复核「全部板块是否有频率标注」的坑
- 板块 id（`sec-0`、`sec-5`）是 JS 运行时分配的，静态 HTML 里搜不到；用 `.part-title` + `chart-freq` 类，71 个板块 20 个带 chart-freq。
- 先写的审计脚本两次读空（定位失败 42/64）却差点当结论——**块定位失败数不为 0 就不能出「完全没有」的结论**。
