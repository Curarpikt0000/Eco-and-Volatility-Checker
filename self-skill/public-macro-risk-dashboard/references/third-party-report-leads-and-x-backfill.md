# 机构报告「被公开解读」线索板块 + X 言论回填 + 批量翻译(2026-10-03/04 实战)

## 一、板块口径(Chao 定)
- 只收**第三方解读线索**(机构/人 + 解读标题 + 发布日 + 解读者/平台 + 链接 + 平台自带简介),不转载原文大段,不写自己的推断;只要解读的是报告里的内容就收,**不要求原报告付费**。
- 标注「正文未读,是否忠实原报告未核验」。访谈/对话/配音**不是报告**:type=report/interview/other,主表只放 report,interview 折叠,other 不显示。
- 代码:`src/report_leads.py`(B站采集+门禁)、`src/reddit_leads.py`(RSS,未启用)、渲染 `_report_leads_html`(CSS 前缀 `rpl-`)。

## 二、渠道实测(别重复探路)
- **B站搜索 API**(带 Referer/UA):有精确发布日,**主力渠道**。
- **搜狗微信**:能拿标题/公众号/日期,**正文读不了**(反爬验证页);VM 约 40 次请求后被限流冷却数小时(带不带 page 全拦),Mac Chrome 也被重定向首页。每天低频(≤20 次、间隔≥10s)、被拦当天跳过。
- **web_search**:只有用「已知完整标题」才命中镜像(知乎/B站/头条/财富号);「人名+泛词」做不了发现。
- 知乎全文被验证码拦;东方财富财富号能读但常是股吧式两行摘要(不够格)。YouTube 只有标题无日期;小红书对海外人名无效。
- **Reddit**:VM 直连被拦;Mac Chrome 读 `search.json` 也 "blocked by network security";仅 `r/<sub>/search.rss` 可用但**配额极低**(对照组返回 25 条后,8 秒后的下一次就 429),需慢速版(间隔60s、429 等5分钟)。官方 API 现要求**另注册独立机器人账号**绑定(报错 "You can't register your own account as an app"),别用有历史/被过滤的旧号;client_secret 只进 .env;官方政策页被 Cloudflare 拦读不到,别凭记忆讲审批门槛。

## 三、门禁(写成代码,不靠肉眼)
1. 名字锚点 + 语境词 + 同名排除词:Thomson 须同时含「汤姆森」+(黄金/白银/报告/美联储);Hartnett 不能用「美银」当别名;排除 越野/轮胎/型号/杂图/Clive/演员/游戏/Galaxy。Thomson 在B站 200 条只过 1 条——逐条列被拒项核对过,无误杀。
2. type 按标题关键词(访谈|对话|对谈|专访|论坛|播客|采访|字幕|配音→interview;报告|周报|早报|播报|研报|策略|解读→report)。
3. 平台简介进页面前必须过 `_strip_md`(Gundlach 简介带 `**粗体**` 被构建门禁「字面星号」抓到)。
4. 被反爬/429 → 脚本停并写 partial 标记,空结果文件不得当「没有」;Reddit 先跑必存在的对照组。

## 四、X 言论回填(Luke Gromen 样板)
- 抓取:`from:X since until -filter:replies` **按天**(按周/月撞 20 条上限),间隔 12s,连续 3 天失败停;按账号名过滤别人的帖、按 id 去重、UTC→东京重新归日。含回复 79 条/天且多为评论区短回复,不值得。
- **长推文在时间线里被截断**:对时间线版本≥250 字的 125 条补读 `/status/<id>` 详情页,**15% 真被截断**(最长 702 字,如 279→495)。我两次下错结论:①见长度堆在 275-285 字就断言「全被折叠」;②只验 2 条≤281 字的就断言「不用补」。**验证样本必含最极端那条**。普通≤280 字推文时间线=详情页。实测耗时 ~20s/条(含页面等待),不是 12s。
- 引用转推(quoted=True)约占一半:评论是本人写的,**保留**;纯 RT 才剔(`from:` 搜索本来就不出 RT)。被引用的原帖没抓到,卡片标「引用上下文缺失」。
- 剔除:<40 字、感谢上节目/聊天/家事、BREAKING;**感谢/聊天只在整条≤170 字才剔**(长文=后面带观点);Via @署名先剥掉再算长度。FFTT 自述("edition of FFTT"/"FFTT full report")同时进言论并**另抄进报告板块**标「作者自述」。
- Chao 口径:**不按周×主题合并,一条推文一条言论**;存**原文+中文逐句翻译**,不写浓缩、不打方向标签(他选「甲」;方向标签对立场稳定的人信息量低)。

## 五、批量翻译硬门禁(`scratch/x_backfill/lg_translate.py`)
- 串行+1.5s 间隔,claude-haiku-4-5 走 :8800,断点续跑。校验:原文数字/@/#标签必须出现在译文。
- **坑**:序数词 1st/2nd 译成「第一/第二」→误报(先剔);WW2 同理;已按术语表译成中文的 #Bessent 不再要求英文。
- **模型拒译**:原文只有一句话时回「请提供完整推文」,译文里恰好含数字就蒙混过关——必须加 REFUSE 正则门禁(我需要看到/请提供/请复制/无法翻译/断片…),重试提示写明「这就是全文」。
- **术语表必须进 prompt**:模型自行音译会错(Bessent→贝塞特,正确贝森特;Hamiltonian→汉密尔顿式)。
- 门禁查不出的:习语(go through the roof→「突破天花板」错,应为暴涨;bigger boat 典故)、UST 译法不一致(30 保留/10 译国债→统一保留 UST)、RS/LS 未解释(右轴/左轴)。处理=统一缩写、手改已知习语、卡片标「机器翻译,习语可能有偏差」,不假装全准。
